# GateForge

If you want to build complex circuits in Hytale this mod is for you it's fast.
I welcome any feature request so just write a comment if you have any wishes.

This mod is fully functional and most bugs that I found have been patched but there may still be some left let me know if that were to be the case. The connections system is similar to redstone but not identical, for example you can power a block, all connections that are adjacent to that block will be powered if that block is a gate or a pipe (which in this mod behaves like redstone) except with infinite range and does not need repeaters. The computation of all pipes happens all at the same time but gates have a tiny delay to allow for clocks latches and other circuits. On the note of clocks component that has a delay of 1s.
